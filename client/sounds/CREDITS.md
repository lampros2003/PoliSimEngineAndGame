# Sounds

The interface sounds in this folder are from Kenney's "Interface Sounds" pack (version 1.0,
www.kenney.nl, https://kenney.nl/assets/interface-sounds), released under Creative Commons
Zero (CC0, http://creativecommons.org/publicdomain/zero/1.0/). Only the files used are kept,
under their names in the pack:

| File | Played when |
|---|---|
| tick_002.ogg | the pointer comes onto a node of the board |
| open_001.ogg | a popup or sheet opens |
| close_001.ogg | a popup or sheet closes |
| click_002.ogg | a slider or field is changed |
| confirmation_001.ogg | a bill is put forward |
| back_001.ogg | a bill is withdrawn |
| pluck_001.ogg | a month has run |
| error_004.ogg | a bill is refused or voted down |
| question_001.ogg | a question is put to the government |
| bong_001.ogg | an election |
